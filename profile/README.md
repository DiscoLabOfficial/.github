# DiscoLab

DiscoLab is an independent open-source software organization focused on experimental tools, systems programming, compiler development, and retro-computing projects.

## Projects

### DiscoC

A freestanding C-like systems programming language and cross-compilation toolchain for specialized and underserved processor architectures.

https://github.com/DiscoLabOfficial/DiscoC
